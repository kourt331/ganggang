# 왕실과 교회의 전쟁 · 제1장

전통 판타지 탑다운 2D 턴제 RPG 프로토타입입니다. Python 게임 로직을 Pyodide로 브라우저에서 실행합니다.

## 실행

`index.html`을 직접 열지 말고 이 폴더에서 정적 웹 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

그 다음 `http://localhost:8000`을 열고 게임을 시작합니다. 첫 실행 시 Pyodide 런타임을 인터넷에서 불러옵니다.

## 조작

- WASD / 방향키: 이동
- E: 대화, 조사, 상호작용
- 숫자 1–4: 대화 선택 / 전투 행동
- Q: 퀘스트와 승급 진행도
- I: 소지품
- H: 회복 붕대

## 현재 프로토타입 범위

숲·마을·교회·왕실 구역, 무작위 종족·성별·시작 진영, 진영별 직업 취득과 퀘스트, 턴제 마물 전투, 장비 구매, 붕대, 사망 페널티, 일부 직업 승급을 포함합니다. 후속 승급, 종교 효과, 정식 폼체인지는 아직 구상 단계입니다.
